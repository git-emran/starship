# 🚀 Welcome to my Starship

My custom Starship prompt design where It matches my tmux. I love designing things and I live in the CLI, So here it is. I use vim btw.

### How to use

Create a create `.config` file if you haven't already. Then create a `starship` folder, this is the best practice to maintain multiple dot files.

Go in the `starship` directory, in the CLI run `touch starship.toml` and then open the file in your IDE or editor. Hopefully in vim or nvim. Then just copy and paste the config, and restart terminal and Done!.

Very easy to understand what is happening in the file. Go to [ starship-docs ](https://starship.rs/config/). to explore more options.
